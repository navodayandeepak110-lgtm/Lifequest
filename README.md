LifeQuest 🎯

LifeQuest is a personal productivity and goal-tracking web application designed to make everyday tasks feel more engaging and motivating.

✨ Features

- 🎯 Set and track your goals
- ✅ Manage daily tasks
- 📈 Track your progress
- 🔥 Stay motivated and build consistency
- 🎮 Gamified experience for completing tasks

🛠️ Built With

- HTML
- CSS
- JavaScript
